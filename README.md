# NoteHub

Next.js App Router application with tag-filtered notes, server-side prefetching, and intercepted note previews.

## Setup

1. Install Node.js 20.9 or newer.
2. Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_NOTEHUB_TOKEN` to your GoIT NoteHub API token.
3. Run `npm install` and `npm run dev`.

The app is available at `http://localhost:3000`. Configure the same token as an environment variable in Vercel before deploying.
